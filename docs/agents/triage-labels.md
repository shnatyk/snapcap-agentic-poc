# Triage Labels

The skills speak in terms of five canonical triage roles. This repo uses pipeline labels instead (see `README.md`), so only one role maps to a real label.

| Label in mattpocock/skills | Label in our tracker | Meaning                                        |
| -------------------------- | -------------------- | ---------------------------------------------- |
| `needs-triage`             | not used             |                                                |
| `needs-info`               | not used             |                                                |
| `ready-for-agent`          | `backlog`            | Fully specified; adding it starts implementing |
| `ready-for-human`          | not used             |                                                |
| `wontfix`                  | not used             |                                                |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table. For a role marked "not used", apply no label.
